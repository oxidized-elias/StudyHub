# Using StudyHub

## Settings and onboarding

Start the interactive tutorial on a fresh installation. It points to actual controls and advances with your actions. Completed onboarding is hidden in Settings until replayed. Choose a study model profile, use **Save & Use Model** to save and activate it, test the connection, select a host-system Obsidian vault folder, and choose the default Note Style. Bullet Points emphasizes short lists; Text Chunks uses paragraphs; Combined uses light explanation with bullets. Notes can override this individually.

## Notes and human review

Expand Add Your Notes to upload supported files; collapse it without losing the current form. Unit number is optional and the author infers a unit name from supplied content. Bulk Unknown Upload processes separate files sequentially. Optional Class / Subject and Course fields apply to every file in the queue; the AI preserves supplied values and infers only whichever field is blank. Lesson and unit name are inferred per file. Enable its optional **Skip human intervention** switch to skip clarification questions and save generated notes without a review pause. It defaults off and applies only to the bulk queue; unreadable content remains marked illegible, and automatic saves do not create human correction lessons. Keep the browser open while its queue submits; individual failures can be retried. Requests are limited to 64 MiB including multipart overhead.

Generation pauses for review. Switch the source pane between AI Transcription and Actual Upload, compare with AI Notes, edit the Markdown, and use Preview/Your Changes to inspect it. Feedback can describe what the AI should learn from your edit. Draft edits autosave; explicit approval writes the final note and a lesson. The AI does not approve drafts for you. Scanned PDFs/images need a vision model; text extraction alone cannot read scanned pages.

Search the subject/course/note tree. Approved notes link to topic indexes, and root/course `BigIdeas.md` files point directly to note files. Mermaid remains available for genuine diagrams; the AI is not required to make relationship graphs for notes. Per-note Clear AI Log removes its prompt/event history while retaining the note and correction lessons.

## Notebooks and sources

Create a notebook with a name, learning goal and optional tutor instructions. Import from the notes tree by expanding folders, selecting entire branches or selecting individual files. You can also upload a folder and select its contents before importing, upload individual PDF/text/Markdown/CSV/JSON sources, paste text, or import supported public webpages. Folder names become part of source titles.

Each source has independent Learn/Quiz toggles. Turn on Learn for explanation context and Quiz for tested material. New study work refreshes imported notes by default; turn refresh off to use saved sources. Old conversations keep their snapshots as notes evolve. Archiving a notebook keeps its history.

## Study modes

| Mode | Interaction |
| --- | --- |
| Guided Learning / notebook chat | Ask about selected sources; receive a brief, cited next question. |
| Step-by-Step Practice | Newly generated applied problems with concrete givens; submit one reasoning step, get feedback, then continue. |
| Quiz | Submit an answer once, eliminate choices before submission, then discuss completed questions with the tutor. |
| Practice Test | Configure count, difficulty, style, sections and timer; answers/feedback stay hidden until completion. |
| Flashcards | Terminology and concise examples with flipping, shuffling and saved progress. |
| Study Guide | A sourced Markdown outline that can be edited as a new revision. |
| Interactive / Canvas | Sandboxed visual activities generated by the model, with persisted activity state. Use native quizzes for ordinary questions. |

Use Enter to submit supported chat/answer fields, Shift+Enter for a newline. Markdown and simple math powers render as you type; the underlying source is retained. The tutor can connect selected notes or create new practice. Source restrictions limit methods to those present in the notes, while allowing new numerical examples. AI correctness is not guaranteed: use citations and correction controls when something seems wrong.

## References, corrections and progress

Click a source reference to open the relevant note heading with highlighting; Back to Learning returns to your mounted session. Closed-book recall reveals only the relevant source section after answering, rather than the full notes. Revealing help is tracked separately from unaided performance.

Check Explanation / Sources and problem correction actions request a sourced review. Corrections are proposed and versioned; they are not silently applied to your notes. Add a personal journal note to any problem, including one you answered correctly. Mastery evidence tracks concepts and mistakes; targeted quizzes mix weaker concepts with known content. There is intentionally no daily review calendar.

## History, jobs and notifications

History includes materials, conversations, attempts/results, jobs and journals. Each supported entry has scoped deletion; active work is protected. Retakes and revisions preserve earlier attempts until you delete them.

Generation continues on the server while navigating the workspace. Open collapsed Live Session Logs for request stages, timing, retries and errors. Kill Task beneath the log panel cancels the active generation; a completed result is retained if it finishes first. Retry creates a new job. Warnings have close buttons; closing does not erase the underlying history.

Completion/review/failure notifications appear in the inbox and as popups. Optional desktop notifications require browser permission. Notifications are checked while the application is open and visible, not through a background push service. Share and export controls are available on materials; shared links remain subject to workspace authentication and can be revoked.

## Subject-wide big ideas

The vault root `BigIdeas.md` links to subject indexes such as `Math/BigIdeas.md` and `Physics/BigIdeas.md`. Each subject index links to shared pages in its `Big Ideas/` directory. A page combines the approved H2 sections for that idea across every course in that subject, with direct links to each original note section. It preserves the separate contributions rather than inventing a combined explanation.

Approving a note adds its H2 big ideas. Reusing a heading adds another contribution to the existing subject idea page, and each note receives links back to its shared ideas. Matching ignores capitalization and repeated whitespace; different wording is not automatically treated as the same concept. The author is prompted to reuse an existing subject idea name when appropriate. Human edits remain authoritative.

Indexes rebuild at startup, approval, vault selection and file deletion. Changed sections replace their earlier contributions, and stale generated pages are removed when no notes use them. Handwritten pages in the directory are retained. Historical course indexes and `Big Ideas.md` subject links still work. The in-app Big Ideas view opens shared pages and original note sections, with Back and Close controls. These files also work as Obsidian vault links.
